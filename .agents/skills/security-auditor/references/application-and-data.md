# Application and data

Start with `apps/backend/src/bootstrap.ts`, its serverless entry point, `src/config`, `src/common`, controllers, guards, Prisma schema and migrations, and `apps/mobile/App.tsx`, active navigation, and `src/services`. Enumerate public, user, provider, operator, job, and internal entry points from the actual routes and wiring.

- Verify authentication and resource-level authorization for each entry point and downstream operation. Cover JWT and SEP-10 claims, expiry and revocation, Ed25519 request identity and intent binding, roles, recipient and account lookup, batch operations, admin routes, health endpoints, and object ownership. Check server-side identity derivation and operator and service-account privilege boundaries.
- Trace signup, OTP, PIN, biometrics, session refresh and logout, device registration, phone or key changes, and recovery. Check one-time use, binding, reset and cooldown state, distributed rate limits, enumeration, lost devices, stolen sessions, recycled numbers, and whether recovery or support can change ownership or signing authority.
- Check SMS/TextBee, QStash, anchors, and external Stellar providers where active. Review signature checks against the intended request bytes and provider identity, freshness and replay handling, callback binding to the correct account and transaction, tolerance of duplicated or delayed messages, credential rotation, and sensitive content in transport or telemetry. Review provider redirects, KYC web views where present, deep links, and untrusted callback or request destinations.
- Review input validation, unsafe data handling, query and command boundaries, URL handling, path/file processing if present, CORS and proxy trust, TLS, error handling, resource limits, and rate limiting across replicas. Verify sensitive actions behave safely when caches, throttle stores, identity services, or integrations are unavailable.
- Review mobile key and token storage, local database, offline PIN and voucher material, backups, clipboard, screenshots, logs, analytics, crash reports, app-link handling, background sync, sign-out and account switching. Check that cached balances and transaction states are scoped to the active account and cannot substitute for server or contract authorization.
- Trace personal and financial data through device, backend, database and cache, SMS, anchors, chain events, backups, logs, support and analytics. Verify least privilege, minimization, isolation, encryption, retention and deletion, including the limitations of immutable on-chain data. Where obligations or provider assurances affect the release decision, record the evidence or owner needed to resolve them.
